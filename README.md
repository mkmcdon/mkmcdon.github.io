# TurnKey Electrical Design website

Static site designed for GitHub Pages.

## Files
- `index.html` — all page content/sections
- `css/style.css` — visual design, layout, colors, responsive behavior
- `js/main.js` — mobile navigation only
- `images/turnkey-key.png` — current key/PCB mark extracted from the provided logo
- `images/logo-source.png` — original uploaded logo, kept for reference
- `CNAME` — custom GitHub Pages domain

## Easy updates
To change text, edit `index.html`.
To change colors/spacing/backgrounds, edit `css/style.css`.
To use your own photos, place them in `images/` and update the relevant image/background reference.

The current site intentionally uses placeholders for project photography because no portfolio images exist yet.
